# DbxToolbox command reference

Generated by `scripts/Build-Docs.ps1`; do not edit by hand. `Get-Help <function> -Full` shows
the details of any command; commands marked "asks first" also take `-WhatIf` and `-Confirm`.

| Command | Function name | Asks first | Synopsis | Parameters |
| --- | --- | --- | --- | --- |
| `dbx` | Invoke-Dbx | no | Any CLI command with your profile and JSON added: dbx schemas get cat.schema |  |
| `dbx-config` | Set-DbxConfig | no | Save default profile, catalog, schema, warehouse, volume or volume path for every session | `-Catalog`, `-Profile`, `-Schema`, `-Volume`, `-VolumePath`, `-Warehouse` |
| `dbx-settings` | Get-DbxConfig | no | Show the current settings and where they are saved |  |
| `dbx-use` | Set-DbxDefault | no | Change catalog, schema or profile for this terminal only: dbx-use cat schema | `-Catalog`, `-Profile`, `-Schema` |
| `dbx-profiles` | Get-DbxProfiles | no | Your saved CLI sign-ins and whether each is valid |  |
| `dbx-me` | Get-DbxMe | no | Who you are signed in as |  |
| `dbx-catalogs` | Get-DbxCatalogs | no | Catalogs you can see |  |
| `dbx-schemas` | Get-DbxSchemas | no | Schemas in a catalog (default catalog if none given) | `-Catalog` |
| `dbx-tables` | Get-DbxTables | no | Tables in a schema; -Filter 'm*' narrows by name | `-Catalog`, `-Filter`, `-Schema` |
| `dbx-volumes` | Get-DbxVolumes | no | Volumes in a schema | `-Catalog`, `-Schema` |
| `dbx-cols` | Get-DbxColumns | no | Columns of a table and their types: dbx-cols my_table | `-Table` |
| `dbx-open` | Open-DbxExplorer | no | Open a table, schema or catalog in Catalog Explorer in your browser | `-Name` |
| `dbx-mkschema` | New-DbxSchema | yes | Create a schema (asks first): dbx-mkschema my_schema [-Comment 'what it holds'] | `-Catalog`, `-Comment`, `-Name` |
| `dbx-mkvolume` | New-DbxVolume | yes | Create a managed volume (asks first): dbx-mkvolume my_volume [-Comment 'what it holds'] | `-Catalog`, `-Comment`, `-Name`, `-Schema` |
| `dbx-rmschema` | Remove-DbxSchema | yes | Delete a schema and everything in it (shows what's inside, asks first): dbx-rmschema my_schema | `-Catalog`, `-Name` |
| `dbx-find` | Find-DbxTable | no | Find tables, or with -Columns columns, whose name contains some text | `-Catalog`, `-Columns`, `-Text` |
| `dbx-count` | Get-DbxCount | no | Row count of a table; -By col1,col2 groups; -Where filters | `-By`, `-Table`, `-Where` |
| `dbx-head` | Get-DbxHead | no | First rows of a table: dbx-head my_table 20 | `-Rows`, `-Table`, `-Where` |
| `dbx-detail` | Get-DbxTableDetail | no | Size, file count, format and last change of a table | `-Table` |
| `dbx-history` | Get-DbxHistory | no | Recent changes to a Delta table (who, when, what) | `-Rows`, `-Table` |
| `dbx-grants` | Get-DbxGrants | no | Who has which permission on a table, schema, catalog or volume | `-Name`, `-On` |
| `dbx-sql` | Invoke-DbxSql | yes | Run SQL, rows back as objects; asks first unless it only reads. -Table, -Csv file, -Clip | `-Clip`, `-Csv`, `-Sql`, `-Table`, `-Warehouse` |
| `dbx-sqlfile` | Invoke-DbxSqlFile | yes | Run a .sql file; statements end with ; at the end of a line | `-Path`, `-Warehouse` |
| `dbx-queries` | Get-DbxQueries | no | Your recent SQL queries: status, time taken, rows, start of the text | `-Rows` |
| `dbx-ls` | Get-DbxFiles | no | List files: dbx-ls (default volume), dbx-ls folder/sub, dbx-ls /Volumes/... | `-Path` |
| `dbx-du` | Get-DbxFolderSize | no | Total size and file count of a folder, including subfolders | `-Path` |
| `dbx-get` | Get-DbxFile | no | Download a file or (-Recurse) a folder to your PC | `-Path`, `-Recurse`, `-To` |
| `dbx-put` | Send-DbxFile | yes | Upload a file or (-Recurse) a folder to a volume (asks first) | `-LocalPath`, `-Overwrite`, `-Recurse`, `-To` |
| `dbx-mkdir` | New-DbxFolder | yes | Create a folder in a volume (asks first) | `-Path` |
| `dbx-rm` | Remove-DbxFile | yes | Delete a file, or a folder with -Recurse (asks first; can't be undone) | `-Path`, `-Recurse` |
| `dbx-warehouses` | Get-DbxWarehouses | no | SQL warehouses: name, ID, state, size |  |
| `dbx-wh-start` | Start-DbxWarehouse | yes | Start a SQL warehouse (asks first; it costs while running) | `-Id` |
| `dbx-wh-stop` | Stop-DbxWarehouse | yes | Stop a SQL warehouse (asks first; stops it for everyone using it) | `-Id` |
| `dbx-jobs` | Get-DbxJobs | no | Jobs you can see; -Name filters (exact name, any case) | `-Name` |
| `dbx-runs` | Get-DbxRuns | no | Recent job runs and how they ended; -JobId for one job | `-JobId`, `-Rows` |
| `dbx-run` | Start-DbxJob | yes | Run a job now (asks first) | `-JobId` |
| `dbx-help` | Show-DbxHelp | no | This list. Get-Help <command> -Full shows the details of one |  |
